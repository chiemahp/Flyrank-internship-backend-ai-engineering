# Assignments and capstone

The assignment brief supplied for this workspace contains titles only. These
standalone examples turn those titles into small, runnable Python projects:

1. `assignment_01_crud_api` — in-memory CRUD REST API
2. `assignment_02_database_api` — CRUD API backed by SQLite and SQLAlchemy
3. `assignment_03_auth_api` — JWT-protected API
4. `assignment_04_docker_fullstack` — server-rendered web app and Docker Compose
5. `assignment_05_ai_api` — API service using the OpenAI chat API
6. `assignment_06_respectful_scraper` — robots-aware, rate-limited scraper
7. `P7_RAG_Document_QA` — PDF knowledge assistant capstone

Each assignment has its own README and dependency list. Run commands from that assignment's directory. Add assignment-specific rubric requirements, if any, before submitting; the implementations cannot infer requirements absent from the supplied brief.
