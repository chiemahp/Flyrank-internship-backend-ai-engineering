🚀 Project Spotlight: Enterprise AI Knowledge Assistant – PDF RAG Capstone

I recently built a Retrieval-Augmented Generation (RAG) application that transforms collections of PDFs into a searchable AI-powered knowledge assistant.

The system ingests PDF documents, creates embeddings, stores them in a persistent Chroma vector database, retrieves the most relevant context, and generates grounded answers using Groq LLMs with source citations for transparency and trust.

🔹 Key Features

✅ PDF ingestion with intelligent text chunking
 ✅ Persistent local Chroma vector storage
 ✅ Local embeddings using all-MiniLM-L6-v2
 ✅ MMR-based retrieval for more relevant context selection
 ✅ AI-generated answers grounded in retrieved documents
 ✅ Source file and page citations for every response
 ✅ Streamlit interface with additive PDF uploads
 ✅ File validation, sanitization, and upload size limits
 ✅ Docker Compose and local deployment support
 ✅ Unit-tested components for reliability
